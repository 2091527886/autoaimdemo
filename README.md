AutoAimDemo 是一个面向 Windows 的实时视觉辅助瞄准端到端延迟P99 7ms（屏幕捕获→推理→跟踪→生成鼠标位）算法整合型演示项目，将屏幕捕获、目标识别、跟踪与运动控制组合成完整流程。它支持 DXGI 和 Windows Graphics Capture 获取画面，使用 TensorRT 加速 YOLO 姿态模型推理，同时识别目标框与人体关键点；结合 CUDA 实现的 OC-SORT 跟踪和目标筛选，维持目标身份并选择瞄准对象。控制方面，项目采用自抗扰控制（ADRC）、误差死区和可配置的光标曲线，调节鼠标移动；还提供目标框、骨架和视野范围等叠加显示，以及帧率和延迟统计。项目的特点是融合这些现代视觉与控制技术，并非声称原创了其中的算法
